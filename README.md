University Network Project

Overview

Designed and configured a University Campus Network using Cisco Packet Tracer.

Objectives

- Configure VLANs for network segmentation.
- Assign IP addresses to PCs.
- Configure switches and routers.
- Test connectivity between network devices.
- Troubleshoot network communication.

Tools Used

- Cisco Packet Tracer
- VLAN
- IPv4 Addressing
- Switching and Routing

Project File

"University Network project.pkt"

How to Run

1. Download the ".pkt" file from this repository.
2. Open Cisco Packet Tracer.
3. Go to File → Open.
4. Select the downloaded project file.
